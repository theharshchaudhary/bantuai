# BantuAI dependencies, grouped by the phase that introduces them.
# Everything here is free to use. Nothing here downloads a model at runtime.

# --- Phase 01: foundation ---------------------------------------------------
google-genai            # primary brain (Gemini Flash, free tier, multimodal)
groq                    # failover brain + Whisper STT
keyring                 # API keys in the OS credential store, never plaintext
python-dotenv           # dev-time .env fallback only

# --- Phase 02: agent core ---------------------------------------------------
winsdk                  # Windows.Media.Ocr, SpeechRecognizer, SpeechSynthesizer
pillow                  # screenshot encoding for vision

# --- Phase 03-04: file and system tools -------------------------------------
psutil                  # processes, CPU, memory, battery, disk
pywin32                 # window management, clipboard, shell integration
pycaw                   # system volume (needs comtypes)
comtypes                # COM bindings pycaw depends on
send2trash              # deletes go to the Recycle Bin, never a hard unlink
watchdog                # filesystem events (also powers proactive triggers later)
AppOpener               # launch installed apps by name
pypdf                   # read_document: PDF text extraction
python-docx             # read_document: DOCX text extraction
openpyxl                # read_document: XLSX text extraction

# --- Phase 05: web tools ----------------------------------------------------
requests
beautifulsoup4
ddgs                    # DuckDuckGo search - no API key, no quota
selenium
webdriver-manager

# --- Phase 06: voice --------------------------------------------------------
edge-tts                # Microsoft neural voices, free, no API key
sounddevice             # microphone capture
numpy                   # audio buffers and the silence gate
pygame                  # mp3 playback that can be stopped mid-sentence (barge-in)
# webrtcvad deliberately not used: it needs a native build on Windows, and an
# energy gate is enough to answer "has this person stopped talking".
# openwakeword is not used: no "Bantu" model exists. See CLAUDE.md, "Wake word".

# --- Phase 07: desktop UI ---------------------------------------------------
PyQt5
keyboard                # global push-to-talk hotkey, no admin rights needed

# --- Phase 08: GUI control --------------------------------------------------
pyautogui               # mouse control; also its corner fail-safe aborts any action
# typing uses `keyboard` (Phase 07) with Unicode events, so Hindi and Nepali type correctly

# --- Phase 09: packaging ----------------------------------------------------
pyinstaller

# Removed in the rewrite: cohere (intent router retired), pywhatkit, mtranslate,
# googlesearch-python, keyboard, rich, pygame.
